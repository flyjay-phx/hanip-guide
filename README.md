# 한입 가이드 (Hanip Guide) — 베타

> 서울 식당 메뉴를 외국인 관광객의 말로: 무슨 음식인지, 얼마나 매운지, 뭐가 들어가는지, 그리고 직원에게 보여 줄 주문 화면까지.

AI 에이전트 3기 Main Quest 2 시제품(PoC)입니다. 번역 앱이 메뉴 **이름만** 바꿔 주는 빈틈을 Claude로 메웁니다.

- [문제 정의서](problem.md) · [모델 선정 근거](model-selection.md) · [검증 보고서](evaluation/report.md)

## 무엇이 다른가
| 번역 앱 | 한입 가이드 |
|---|---|
| "항정살" → 글자 그대로 옮긴 이름 | "Pork jowl" + 어떤 부위를 어떻게 먹는지 한 줄 설명 |
| 맵기 정보 없음 | 고추 0~3개 |
| 재료 정보 없음 | 돼지고기·소고기·해산물·날것 표시, **확신 정도**까지 |
| 내 조건과 상관없음 | 못 먹는 것을 고르면 걸리는 메뉴에 경고 |
| 말로 주문해야 함 | **직원에게 보여 주는 큰 한국어 주문 화면** + "돼지고기 들어가나요?" 질문 카드 |

## 화면 흐름
1. **언어·조건 고르기:** English / 日本語 / 中文, 못 먹는 것(돼지고기·소고기·해산물·날것·매운 것)
2. **메뉴 넣기:** 홍대 샘플 메뉴판 7개 중 고르거나 메뉴 이름을 한 줄씩 입력
3. **메뉴 카드:** 한국어 이름·발음·현지어 이름·설명·맵기·재료 칩. 내 조건에 걸리면 빨간 "Not for you", 모르면 주황 "Ask first"
4. **질문 카드:** 확실하지 않은 재료 칩을 누르면 직원에게 보여 줄 "이 ○○에 돼지고기가 들어가나요?" 화면과 네/아니요 버튼
5. **주문 화면:** 담은 메뉴와 요청(덜 맵게, 포장 등)을 크게 한국어로
6. **실험 탭 (`#/lab`, 한국어):** 정답표, AI 채점, 번역 앱과 O/X 비교

## 안전 설계
- **AI 추정은 "없음"을 확정하지 못합니다.** AI가 "없음"이라고 해도 화면에는 "보통 없음"으로 낮춰 보여 주고 직원에게 묻는 카드를 붙입니다(`core.apply_safety`). 식당마다 조리법이 다르기 때문입니다.
- 사람이 검수한 **메뉴 사전**(`data/dictionary.json`)에 있는 메뉴만 "확인된 정보"로 보여 줍니다. 사전에 없을 때만 AI를 부릅니다. 베타에서는 사전이 비어 있고, 정답표 검수가 끝난 메뉴부터 옮겨 담습니다.
- AI가 실패하면 꾸민 답을 보여 주지 않고 오류를 그대로 알립니다.
- 모든 화면에 "알레르기·종교 식단은 반드시 직원에게 확인하세요" 안내가 있습니다.

## 구조
```
web/ (폰 화면, 빌드 없음)  ──fetch──▶  server.py (127.0.0.1:8770, 표준 라이브러리만)
                                         │
                                         ▼
                                       core.py
                                         ├ 입력 정리 (가격·중복 제거, 30개·40자 제한)
                                         ├ 메뉴 사전 먼저 찾기
                                         ├ 없으면 Claude Code CLI (도구 끔, JSON 스키마 강제)
                                         ├ 답 검사 + 안전 규칙
                                         └ runs/<메뉴판ID>/board.json 저장
data/  samples.json(홍대 7곳 메뉴 이름) · answer_key.json(정답표) · dictionary.json(검수 사전)
evaluation/  AI 채점 결과 · 번역 앱 비교 결과 · 보고서
```

## 실행
필요: Python 3.11 이상, 로그인된 [Claude Code](https://code.claude.com/docs/en/cli-reference). 추가 Python 패키지는 없습니다.

Windows에서는 `시작하기.cmd`를 두 번 누릅니다. 직접 실행하려면:
```powershell
python server.py          # http://127.0.0.1:8770
python -m unittest discover -s tests   # 자동 테스트 12개 (실제 AI는 부르지 않음)
```
폰 크기로 보려면 브라우저 개발자 도구에서 모바일 보기를 켜세요.

## 샘플 메뉴판
홍대 주변 7곳(조폭떡볶이, 동보성, 새마을식당, 감나무집 기사식당, 교촌치킨, 백년토종삼계탕, 스시지현)의 메뉴 이름 7개씩입니다. 2026-11-17에 공개 웹 페이지에서 확인한 **이름만** 담았고, 가격·사진·소개 문구는 담지 않았습니다. 식당과 관계없는 비공식 자료이며 현재 메뉴판과 다를 수 있습니다.

## 한계 (베타)
- 메뉴판 사진 인식은 아직 없습니다. 글자로 넣어야 합니다.
- PC에 로그인된 Claude로 돌기 때문에 이 PC에서만 씁니다. 배포는 다음 단계입니다.
- 채식 판정은 없습니다(닭고기·육수 표시가 아직 없음).
- 정답표와 O/X 판정을 한 사람이 했습니다.

## 다음 단계 (상용화 방향)
1. 현장 베타: 메뉴판 사진 입력, 폰 웹 배포, 서버에서 Claude API 호출, 실제 관광객 사용 기록
2. 메뉴 사전 키우기: 검수된 메뉴는 AI를 부르지 않아 빠르고 비용이 들지 않음
3. 식당용 QR 메뉴판: 메뉴판 단위로 저장해 둔 결과(`runs/<ID>`)를 식당이 손님에게 QR로 제공
